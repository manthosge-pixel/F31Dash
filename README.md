# F31 Dash – BMW 316i F31 (N13) ENET dashboard

Android app (Kotlin + Jetpack Compose) που διαβάζει δεδομένα από το αυτοκίνητο μέσω του Vgate **ENET Wi-Fi** (δίκτυο `WIFI_ENET`).

## Άνοιγμα / εγκατάσταση
1. Αποσυμπίεσε το zip και άνοιξε τον φάκελο `F31Dash` στο **Android Studio** (File → Open).
2. Περίμενε το Gradle sync (κατεβάζει μόνο του ό,τι χρειάζεται).
3. Κινητό με USB debugging → ▶ Run.

## Δοκιμή χωρίς αυτοκίνητο
SETTINGS → **DEMO MODE** ON: οι δείκτες κινούνται με ψεύτικα δεδομένα.

## Σύνδεση με το αυτοκίνητο
1. Μίζα ON (ή μηχανή αναμμένη).
2. Wi-Fi κινητού → `WIFI_ENET` (πες "μείνε συνδεδεμένος" χωρίς internet).
3. Κλείσε το BimmerLink (μόνο μία εφαρμογή μπορεί να μιλάει στο αυτοκίνητο).
4. Η εφαρμογή βρίσκει το αυτοκίνητο μόνη της (UDP 6811 → TCP 6801, HSFZ/UDS).

## Από πού έρχεται κάθε τιμή
Η οθόνη **SENSORS** δείχνει για κάθε τιμή: ζωντανή τιμή, πηγή, ωμή απάντηση.
Μορφή πηγής: `ECU DID BYTES FACTOR OFFSET [s]` — τιμή = raw × FACTOR + OFFSET.

| Τιμή | Προεπιλογή |
|---|---|
| RPM, ταχύτητα, νερό, αέρας, MAP, πεταλούδα, μπαταρία, fuel trim, λάμδα/AFR, λάδι, χρόνος λειτουργίας | Standard OBD DIDs `F4xx` στο DME (`12`) |
| Boost | Υπολογίζεται: MAP − βαρομετρική |
| Σχέση, πίεση λαδιού, θερμοκρασία κιβωτίου | **Κενό** – BMW-specific, χρειάζεται DID |

Το πεδίο **TEST** στέλνει οποιαδήποτε εντολή UDS (π.χ. ECU `12`, `22 F4 0C`) για να βρούμε τα BMW DIDs.

## Οθόνες
DASH · GRAPHS · CODES (διάβασμα/σβήσιμο σφαλμάτων DME/EGS) · 0-100 · TRACK (επόμενη έκδοση) · SETTINGS · SENSORS
